# Serenity Ranch

Landing page for **Serenity Ranch First Responder Recovery** — a residential treatment program designed exclusively for first responders.

## Preview

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 5173
```

Then visit http://localhost:5173

## Stack

- Static HTML / CSS / JS
- Google Fonts: Cormorant Garamond + Montserrat
- Unsplash imagery for facility photography placeholders
